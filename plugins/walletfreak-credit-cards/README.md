# WalletFreak Credit Cards

Card benefits, wallet profile, payment and points comparisons, and requested rewards balance checks. Requires the WalletFreak Travel core plugin for the shared private local server and wallet. Run `python3 <core>/scripts/local.py start --view wallet` to open Wallet; this package starts no second server. The core plugin bundles the card, loyalty-program and dashboard template catalogs used by this skill package.
