# Check requested balances

Run only for an active request. Identify the requested provider/program and owner alias from the conversation; clarify ambiguous ownership before accessing an account. Never combine different people's balances or infer a card product from portal access.

Discover core's `travel-plan` and `provider-research` through the host and follow their shared browser/login guidance. Use the existing `walletfreak-browser` connection and official provider page. Reuse a verified signed-in session; otherwise open sign-in, notify the user to log in in Chrome and handle MFA/CAPTCHA, then wait for confirmation. Verify a non-sensitive authenticated view before reading the requested balance page. Never request, type, read or store passwords/codes, inspect filled forms, or read old credential/config files.

Read only requested available points/miles and membership status. Keep pending points separate and preserve the provider's exact tier name; card benefits are not proof of active status. Record owner alias, program, available/pending amounts, status, observation time and a public source URL without member identifiers. If blocked or ambiguous, retain prior dated facts and report the gap instead of inventing an update.

When the user also requests remaining card credits or issued certificates, select the exact card from the bundled [catalog](../../cards.json) and follow its product guide through card-travel-benefits. Record each allowance's actual remaining amount, period and owner separately; a program balance or advertised annual maximum does not establish unused card benefits.

Return a dated comparison of prior reports and observed balances in conversation. Update a private non-secret traveler profile only when requested, following traveler-profile's file safeguards; preserve unrelated fields and never change a date for an unverified fact. Upcoming bookings are reviewed only when requested, through travel-plan/confirmation-import. No dashboard queue, saved sign-in, account database or background sync is needed. Never enroll, redeem, transfer, reserve, purchase or alter a provider account.
