      Transaction spreadsheet (CSV)

      Transaction spreadsheet

      Download transactions CSVDownload category totals CSV

      Download activity from your bank, then import it here. Files are processed on this device. No bank credentials required. This is a local spending ledger, not a tax report.

      Import downloaded activity

      Check one known purchase against the preview. Debit/Credit columns override the sign setting. Dates must include a year: YYYY-MM-DD or US month/day/year. Amounts support up to two decimal places.

      One account per import, up to 10,000 transactions in the ledger and 1.2 MB per file. PDF, scanned and Excel statements need conversion and reconciliation first; the Spending skill includes bank-specific guides. Original downloads are not stored by this app.

      Positive = money out; negative = money in. Confirm each category and transaction type. “Approve this page” skips unknown types and possible duplicates. Payments, transfers and income are excluded from spending totals. Refunds reduce spending in the month received.

      Monthly category totals

      Approved expenses minus approved refunds, grouped by currency. Totals cover the complete ledger; search and page filters apply only to the transaction table.
